# 🖥️ Custom PC Build – Intel i3-9100F

## 📌 Overview
This project documents the assembly and configuration of a custom desktop computer built for general use and light gaming.

---

## ⚙️ Specifications

- **CPU:** Intel Core i3-9100F  
- **Motherboard:** Gigabyte B365M AORUS Elite (Micro ATX)  
- **RAM:** 8GB (2x4GB) 2666MHz HyperX Fury  
- **Storage:** 1TB Western Digital Blue HDD  
- **GPU:** MSI GTX 1650 Ventus XS OC 4GB GDDR6  
- **PSU:** EVGA 600W 80+ Bronze Semi-Modular  
- **Case:** Sharkoon TG4  

---

## 🔧 Build Process

1. Installed CPU and cooler  
2. Installed RAM in dual channel  
3. Mounted motherboard into case  
4. Installed PSU and connected cables  
5. Installed GPU  
6. Managed cables  
7. First boot and BIOS setup

- Installed operating system  
- Installed drivers
